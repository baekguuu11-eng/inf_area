INFECTED AREA - Chernobyl V10 Overhaul
Base: V9 Chernobyl First Pass

핵심 변경
1) 체르노빌 보스룸 전체를 6 x 4 고정 격자로 사용.
   - 새 패턴은 무작위 셀 뽑기 대신 고정 격자 좌표 위에서 작동.
   - 좌->우 / 우->좌 / 위->아래 / 아래->위 순차 폭발.
   - 양옆->중앙 / 중앙->양옆, 상하->중앙 / 중앙->상하.
   - 체커보드 A/B, 반전 연쇄, 사전 정의 안전지대 이동.
   - 최근 패턴과 같은 계열 반복을 피하는 히스토리 기반 선택.

2) 지속 공격 대응 시스템.
   - 약 2.3~3.2초 수준의 연속 유효타가 누적되면 체르노빌이 강제 이동 패턴 사용.
   - 근거리: CORE PURGE (중앙부 대형 방출, 최종 단계 추가 충격파).
   - 원거리: CONTAINMENT (플레이어가 있던 행/열을 잠그고 2페이즈 이후 인접 구역 연쇄).
   - 발동 후 내부 쿨다운, 공격을 멈추면 누적치 빠르게 감소.

3) URP/카메라 CG.
   - ChernobylCameraFX 런타임 Volume: Bloom, Vignette, Chromatic Aberration,
     Color Adjustments, Lens Distortion, Film Grain.
   - 페이즈 전환/폭발/스윕/지속공격 대응 때 순간 후처리 펄스.
   - MELTDOWN에서는 아주 약한 화면 호흡과 노심 불안정 후처리.
   - 기존 CameraFeedbackController를 사용한 방향성 쉐이크와 결합.
   - 픽셀아트를 과도하게 흐리지 않도록 Motion Blur / DOF는 사용하지 않음.
   - 코어에 URP Light2D를 런타임 추가해 페이즈별 녹색/황록 발광 강도 상승.

4) 경고 표시 업그레이드.
   - 예고 -> 충전 -> 폭발 직전의 3단계 색/점멸 변화.
   - 녹색 위험 표시가 마지막에 황색/백색 과열로 올라감.

주의
- Unity Editor/Play Mode 실행 검증은 이 환경에서 수행하지 못함.
- ZIP 무결성, C# 구조/괄호, .meta GUID 중복 검사는 별도 수행.
