INFECTED AREA - Executor Boss V7 Combat Polish
Base: V6 ArtStages

이번 버전은 사용자가 최근 요청한 항목만 반영하며, 이전에 해결된 버그/기능은 의도적으로 다시 건드리지 않았다.

[1] DEBUG WHIP 시각 범위 동기화
- 실제 공격 판정 거리 자체는 변경하지 않음.
- 기존에는 판정이 visibleReachMultiplier(2.15)를 사용하지만 TrailRenderer는 실제 짧은 스프라이트 끝점을 따라가 시각적으로 사거리가 짧아 보였음.
- 채찍 공격 중 실제 최종 판정 끝점까지 보라색 WhipReachVisual LineRenderer를 표시.
- 아크 트레일도 실제 판정 끝점을 추적.
- 결과: 보이는 채찍 끝 = 실제 최대 공격 판정 끝.

[2] SHOTGUN 근거리 버프
- 극근접 <= 1.10 world unit: 피해 x1.55.
- 1.10 ~ 2.00: x1.25에서 x1.00까지 부드럽게 감소.
- 그 이상은 기존 거리 감쇠 그대로.
- 펠릿 수/산탄각/탄약 소모/연사간격은 유지.

[3] MACHINE GUN 밸런스 버프
- 탄환 1발 피해: 7 -> 9.
- attackInterval: 0.080 -> 0.074.
- minimumAttackInterval: 0.050 -> 0.045.
- 이론상 기본 지속 DPS 약 +39%.
- 탄약 소모/탄창/재장전/탄퍼짐은 그대로라 높은 지속 화력의 대가로 탄을 빠르게 소모함.

[4] 무기 변경 즉시 HUD 탄약 동기화
- 무기 변경 이벤트 발생 즉시 현재 무기의 탄창 잔량/예비탄을 강제 Refresh.
- Canvas 즉시 갱신.
- Update + LateUpdate 안전 동기화로 Debug Hotkey/Tab/상점 장착 등 경로에서도 이전 무기의 탄약 숫자가 남지 않게 함.
- 재장전/탄약 획득 이벤트도 기존 AmmoChanged 시스템과 함께 즉시 반영.

[5] 집행자 하단 절단감 보정
- 원형/타원형 받침대는 다시 만들지 않음.
- VisualRoot를 약간 더 아래(-0.12)로 내려 본체 하단을 지면에 묻음.
- GroundRevealMask의 바닥 경계를 1~3픽셀 불규칙하게 만들어 직선으로 잘린 듯한 하단 실루엣을 완화.
- 실제 보스 루트/피격 콜라이더 위치는 유지.

[6] 일반 정밀 포격 페이즈별 대구경화
- 1페이즈: 반경 1.15 (기준).
- 2페이즈: 반경 1.38 (약 x1.20).
- 최종 집행 <=15%: 반경 1.61 (약 x1.40).
- 경고 원 / 실제 피해 반경 / 폭발 GIF 지름을 같은 radius 기반으로 동기화.
- 반경이 커질수록 먼지/파편/폭발음/카메라 흔들림도 단계적으로 강화.
- 3연속 포격(Chain Artillery)과 8연발 포격의 기존 착탄 반경은 그대로 유지.
- 기존 2페이즈 착탄 후 4방향, 최종 집행 8방향 투사체 규칙 유지.

[7] 8연발 포격 실시간 추적
- 8개 착탄 위치를 공격 시작 시 미리 계산하지 않음.
- 매 포탄을 위로 발사한 직후 최신 플레이어 위치를 다시 읽어 경고 지점을 생성.
- 3/5/7/8번째 일부 탄에는 0.18~0.30초의 짧은 이동 예측 적용.
- 플레이어가 이동하면 8개의 경고가 실제 이동 경로를 따라 이어짐.
- 8발 발사 완료 후 착탄을 기다리지 않고 다음 공격으로 즉시 복귀하는 기존 규칙 유지.

[검증]
- 수정 C# 8개 파일의 문자열/주석 제외 괄호, 소괄호, 대괄호 균형 검사 통과.
- ZIP 생성 후 unzip 무결성 검사를 수행할 것.
- Unity Editor가 이 실행 환경에 없으므로 실제 Unity 컴파일/Play Mode 검증은 수행하지 못함.
