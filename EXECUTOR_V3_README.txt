INFECTED AREA — EXECUTOR BOSS V3

적용 기준
- Unity 6.4 (6000.4.1f1)
- V2 전체 개발본을 기반으로 V3 개선
- 상점 UI/상점 프리팹/기존 Canvas는 수정하지 않음

V3 핵심 변경
1. 집행자 지면 고정감
- GroundSocketBack / GroundSocketFront / GroundSocketCracks 추가
- 본체 하단을 전면 림이 실제로 가리도록 구성
- 본체 위치 하향, 크기와 그림자 조정
- 정지 상태에서도 지하 장치에 박혀 있는 실루엣 유지

2. 등장 컷신 전면 재구성
- 독립 시네마틱 상·하단 바
- 플레이어/포탈 집중 → 포탈 압축 소멸
- 카메라가 방 중앙 지면으로 실제 이동·줌인
- 지면 압력, 균열, 먼지, 파편 단계적 강화
- 느린 상승 → 멈칫 → 폭발적 돌출
- 눈과 발사구 클로즈업
- 집행자 타이틀 공개 후 축소된 상단 체력바 전개
- 카메라 전투 위치 복귀
- 아무 버튼 스킵 시 모든 상태를 전투 시작 상태로 정리

3. 잠복/돌출 정체성 강화
- 소켓 해제와 본체 압축
- 잠복 직전 먼지·파편이 구멍 안쪽으로 흡입
- 지중 이동 융기와 회백색 먼지 궤적
- 돌출 경고를 포격 조준경과 분리하고 불규칙 균열로 표현
- 돌출 직전 짧은 정적
- 큰/작은 파편, 먼지 2중 폭발, 금속 스파크
- 방향성 카메라 펀치, 히트스톱, 오버슈트, 착지 반동
- 잠복 강제 주기 1페이즈 13초 / 2페이즈 10초

4. HUD
- 내부 칸 구분 없음
- 체력바 폭과 높이 축소
- 영문 부제 제거, 갈무리 폰트 ‘집행자’만 표시
- 최근 피해는 더 밝은 연속형 붉은 구간
- 텍스트 겹침 제거

5. 2페이즈 전달
- 1.35초 미니 컷신과 카메라 줌
- ‘과부하’ 표시와 화면 붉은 플래시
- 탄환 정리 후 전환
- 눈/발사구 청색 → 주황·적색
- 지면 균열 적색 점등
- 지속 연기와 스파크
- 2페이즈 탄환 색을 주황·적색으로 영구 변경
- HUD 색상도 2페이즈에 맞춰 변화

6. 플레이어 사망
- 보스 패턴/투사체/HUD는 정리
- 현재 보스 BGM은 끊지 않고 약 88% 볼륨으로 유지
- Retry 또는 메뉴 이동으로 장면이 바뀔 때 종료

7. 공격 시각 구분
- 조준탄: 청백색(2페이즈는 주황)
- 확산탄: 작은 청자색(2페이즈는 적색)
- 방향성 꼬리 표현 추가
- 보스 눈이 플레이어를 미세하게 추적
- 피격 위치에 금속 스파크 추가

주의
- Unity Editor를 이 환경에서 실행할 수 없어 정적 검사와 파일 무결성 확인까지만 완료함.
- 첫 실행 시 Console 빨간 오류와 실제 카메라 줌/파편 양을 Play Mode에서 확인할 것.
- 사망 전용 PNG는 Assets/Resources/Bosses/Executor/ExecutorDeath.png로 추가하면 자동 사용됨.
