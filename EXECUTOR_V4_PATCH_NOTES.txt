INFECTED AREA — EXECUTOR BOSS V4
Unity: 6000.4.1f1

핵심 변경
1. 등장 컷신 전면 재구성
- 포탈 소멸 연출 제거
- 컷신 중 기존 HUD/상점 Canvas를 런타임에서만 숨김
- 컷신 중 기존 음악 음소거, 집행자 효과음만 재생
- 카메라가 플레이어에서 바닥으로 천천히 이동/확대
- 지하 진동, 균열, 먼지, 큰/작은 파편을 단계적으로 강화
- 집행자 1차 상승 → 중간 정지 → 최종 돌출 → 눈 클로즈업
- 시스템 문구와 '집행자' 이름을 한 글자씩 출력하고 기계 클릭음 재생
- 컷신 종료 직전에 기존 HUD 복구, 보스 체력바와 1페이즈 BGM 시작
- 우하단 독립 스킵 안내 유지

2. 지면 고정 표현
- 디스크 아래에 보이던 불필요한 반원 제거
- GroundSocketFront를 얕은 전면 립 형태로 변경
- 본체 하단이 전면 립에 가려져 지면에 박힌 느낌 강화

3. 정밀 포격
- 상단 발사구에서 실제 포탄이 위로 상승
- 포탄이 화면 밖으로 나간 뒤 목표 지점에 경고 표시
- 실제 낙하 포탄이 위에서 떨어져 지면에 충돌
- 2페이즈 연쇄 포격도 실제 포탄 3발을 순차 발사/낙하시킴

4. 폭발 GIF 적용
- 업로드된 explosion_1.gif를 8장의 투명 PNG 프레임으로 변환
- 집행자 포격 착탄의 중심 폭발 애니메이션으로 사용
- 자폭 몹 폭발에도 같은 애니메이션 사용
- 보스 포격에는 먼지, 파편, 화면 흔들림을 추가해 차별화

5. 사운드
- 컷신 진동, 금속 균열, 최종 돌출, 기계 기동, 글자 타건,
  포격 발사/낙하/폭발, 잠복, 2페이즈 과부하용 WAV 포함
- 포함된 WAV는 이 패치용으로 직접 생성한 오리지널 효과음
- 외부 제3자 사운드 바이너리는 포함하지 않음
- 상세: Assets/Resources/Bosses/Executor/Audio/AUDIO_SOURCES.txt

6. 기존 요구 유지
- 체력바 내부 칸 없음
- 플레이어 사망 시 보스 패턴/HUD는 정리하지만 현재 보스 BGM은 계속 재생
- 기존 상점 프리팹, 상점 스크립트, 기존 Canvas 프리팹은 수정하지 않음

패치 적용
- V3.1 전체 프로젝트에 PatchOnly ZIP의 Assets 폴더를 그대로 덮어쓰기
- 전체 프로젝트 ZIP 사용 시 Unity Hub에서 INFECTED_AREA_EXECUTOR_DEV_V4 폴더 열기

주의
- 정적 파일 검사와 ZIP 무결성 검사는 완료했으나,
  이 환경에서는 Unity Editor의 실제 컴파일 및 Play Mode 테스트를 실행할 수 없음.
- Unity에서 처음 연 뒤 Console의 빨간 오류부터 확인할 것.
